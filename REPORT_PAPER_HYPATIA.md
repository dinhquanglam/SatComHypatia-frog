## 1. Introduce about Hypatia project

Hypatia is a research framework for studying low-Earth-orbit Internet constellations end to end. It combines four layers:

1. `satgenpy`
   Generates constellation geometry, inter-satellite links, ground stations, and forwarding state over time.
2. `ns3-sat-sim`
   Simulates packet-level network behavior in ns-3 using the time-varying satellite state generated by `satgenpy`.
3. `paper`
   Contains the exact experiment orchestration used for the IMC 2020 paper, including analysis and figure generation.
4. `satviz`
   Produces Cesium-based interactive 3D visualizations of constellation paths and utilization.

The `paper` directory is the reproduction package for the original IMC 2020 Hypatia results. Its purpose is not only to run one simulation, but to regenerate the complete analysis pipeline:

- constellation dynamic state
- theoretical post-analysis
- ns-3 packet-level experiments
- publication figures
- interactive satviz HTML visualizations

Fixes:

- change the loop in `basic-simulation.cc` to `for (const auto& key_val : m_config)`

4. This branch also required `gurobipy` to be available during the overall build/runtime workflow.

Fix:

- ensure `gurobipy` is installed in the container image before rerunning the build

5. `screen` was required later by analysis helpers and had to be present in the image already.

Fix:

### 2.5 Practical workflow: restore official temporary data

The full original pipeline is very slow. The recommended practical method is to restore the official pre-generated temporary data and then regenerate plots and figures from that restored dataset.

Command:

```bash
curl -L --fail -o paper/hypatia_paper_temp_data.tar.gz \
  https://github.com/snkas/hypatia/releases/download/v1/hypatia_paper_temp_data.tar.gz

shasum -a 256 paper/hypatia_paper_temp_data.tar.gz
```

Expected checksum:

```text
18d761a28706723b57772e0636fbc40b7d57161f4c54069eede0c8ae740cbe2d
```

Purpose:

- downloads the official temporary data archive used to avoid multi-hour regeneration
- checksum validation confirms archive integrity

Command:

```bash
docker compose exec -T hypatia-dev bash -lc 'cd /workspaces/SatComHypatia-frog/paper && printf "yes\n" | python3 extract_temp_data.py'
```

Purpose:

- extracts the temporary data archive into `paper/`
- restores the state required for plotting without regenerating every dynamic-state and ns-3 run from scratch

This is the only workflow used for the validated reproduction in this workspace.

I did not use the full from-scratch regeneration path for the final successful `paper` reproduction because restoring the official temporary data was sufficient to regenerate all paper plots and satviz outputs.
